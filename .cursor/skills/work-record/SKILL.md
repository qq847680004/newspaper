# 工作记录模板生成

运行本目录下的 `generate.sh`（必须在 Git Bash 下执行，脚本依赖 GNU date 的 `-d`）：

```
bash .cursor/skills/work-record/generate.sh
```

脚本行为：

- 自动计算当前自然周的周一（周一为一周起点），列出周一到周五五个日期
- 周目录命名与 weekly-report skill 一致：第 N 周 = 该月第 N 个周一所在的工作周，如 2026-08-24 → `2026-08-第四周`
- 日期归属与 weekly-report 读取日报的规则严格一致，按日期归月：与周一同月的日期留在该月第 N 周目录（如 8/31 → `2026-08-第五周`）；跨月周（如 8/31~9/4）里跨入下月的日期（9/1~9/4）放到 `newspaper/daily/下月-第一周/`（与下月第一周的日报同目录，靠日期过滤区分），不在周一所在月的目录里列出下月日期
- 非跨月周生成一个 `work-record.md`；跨月周生成两个（各月目录下一个），每个文件独立判断已存在
- 在 `newspaper/daily/YYYY-MM-第N周/` 下生成 `work-record.md`，目录不存在则创建（含 `newspaper/daily/` 本身）
- 每个日期单独一行，等号左右各 12 个：`============2026-08-24============`，日期之间空 6 行
- 目标文件已存在时不覆盖、不追加，输出提示后结束

生成完成后，把文件路径和内容展示给用户。
